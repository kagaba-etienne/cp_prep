# Square root and square square
> Input file: stdin <br/>
Output file: stdout <br/>
Time limit: 1 sec <br/>
Memory limit: 256 mb

Find such a number $x$ such that $x^2+\sqrt{x}=C$, to an accuracy of at least 6 digits after the dot.

**Input**

A single line contains the real number $1\le C \le 10^{10}$

**Output**

Output one number — the $x$ you are looking for.

**Examples**
---
**Input 1:**
```
2.0000000000
```

**Output 1:**
```
1.00000000000000000000
```
---
**Input 2:**
```
18.0000000000
```

**Output 2:**
```
4.00000000000000000000
```
---
