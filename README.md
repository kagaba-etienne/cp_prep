# CP Prep

Welcome to the **CP Prep** repository! This repository contains solutions to various competitive programming problems implemented in different programming languages. Each language has its own folder with a dedicated README and solutions.

## Folder Structure

- [C++ Solutions](./c++/): Solutions implemented in C++.
- [Java Solutions](./java/): Solutions implemented in Java.
- [JavaScript Solutions](./javascript/): Solutions implemented in JavaScript.
- [Python Solutions](./python/): Solutions implemented in Python.

Within each language folder, solutions are further organized into subfolders by their problem name. For example:
1. `A. Moving Chips/moving_chips.cpp` (for C++)
2. `A. Moving Chips/moving_chips.java` (for Java)
3. `A. Moving Chips/moving_chips.js` (for JavaScript)
4. `A. Moving Chips/moving_chips.py` (for python)

The README files in each language folder contain links to the online judges where the solutions were tested.

## How to Use

1. Navigate to the folder of your preferred programming language.
2. Explore problem statements listed in the respective README files.
3. Open the subfolder for a specific problem to view its solution.

Happy coding!
